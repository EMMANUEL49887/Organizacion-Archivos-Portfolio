# Sistema de Control de Acceso

## Descripción

Sistema desarrollado para registrar entradas y salidas de usuarios utilizando archivos de texto.

## Objetivo

Implementar una solución de almacenamiento de registros mediante archivos secuenciales.

## Tecnologías Utilizadas

- Python
- Archivos TXT

## Estructura del Proyecto

- src/: código fuente
- data/: archivos de datos
- docs/: diagramas y documentación

## Formatos de Archivo Utilizados

- TXT: almacenamiento de registros de acceso.

## Ejecución

1. Ejecutar main.py
2. Ingresar los datos solicitados.

## Evidencias

Las capturas y diagramas se encuentran en la carpeta docs.
