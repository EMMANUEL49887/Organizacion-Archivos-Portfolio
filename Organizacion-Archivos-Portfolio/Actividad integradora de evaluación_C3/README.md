# Actividad integradora de evaluación_C3

## Descripción
El objetivo de esta actividad es desarrollar una aplicación en Python para procesar y analizar datos de ventas de una tienda de tecnología. A través de archivos CSV y el uso de las librerías Pandas y Matplotlib, se organiza la información, se calculan ingresos y cantidades vendidas, y se generan representaciones gráficas que permiten visualizar los resultados de forma clara. Esto facilita la identificación de tendencias de venta y proporciona información útil para la toma de decisiones empresariales.

## Objetivo general

Analizar las ventas de una tienda de tecnología mediante una aplicación desarrollada en Python.

## Objetivos específicos

Leer datos desde un archivo CSV.
Procesar información utilizando Pandas.
Calcular ingresos y ventas por producto.
Identificar los productos más vendidos.
Generar gráficas con Matplotlib.
Presentar los resultados de forma clara y comprensible.
